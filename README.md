# RAIT-ACM-KLEOS: Dynamic Compliance & Local Tax Intelligence Pipeline

A production-ready, edge-optimized compliance orchestration backend designed for the small Indian business ecosystem. This pipeline ingests structured transaction outputs generated by OCR layers, passes them through a deterministic mathematical audit system, validates them against government purchase ledgers, and spins up an interactive, offline, multilingual conversational interface for auditing.

---

## 🏛️ System Architecture Workflow

The system is engineered as a decoupled, multi-layer hybrid verification pipeline:

[Incoming Structured OCR Payload]
│
▼
Layer 1: Structural Blueprint Safeguard (Type Guards)
│
▼
Layer 2: Deterministic Rule Auditing (Horizontal/Vertical Math checks)
│
▼
Layer 3: Local B2B Purchase Reconciliation (Pandas Database Parsing)
│
▼
Layer 4: Edge Intelligence & Multilingual AI Interface (Llama 3.2 Offline)


1. **Blueprint Validation**: Dynamically detects raw type payloads (unwrapping batch list contexts down to transactional objects) to safeguard underlying operational tracks.
2. **Deterministic Rule Auditing**: Cross-references cryptographic HSN codes against statutory GST parameters to isolate vendor misclassification risks, computes vertical balances, and extracts state code prefixes to catch regional tax application anomalies (IGST vs. CGST/SGST).
3. **Local Ledger Reconciliation**: Queries extracted parameters directly against historical system logs (`GSTR2B_Dummy_Dataset.xlsx`) using high-performance relational indices to generate matching compliance flags.
4. **Edge Intelligence Routing**: Channels execution diagnostics into a locally hosted parameter block without relying on external cloud endpoints, utilizing prompt token barriers to ensure high-speed language mirroring (English-to-English, Hinglish-to-Hinglish).

## ⚡ Prerequisites & Environment Setup

This pipeline is optimized to run completely offline on local client hardware with zero external API dependencies or execution costs.

### 💻 1. System-Level Dependencies

Ensure the host machine has the following frameworks installed:

* **Python 3.10 - 3.12**: Download via [python.org](https://www.python.org/downloads/). 
  * *⚠️ CRITICAL: Ensure you check the "Add python.exe to PATH" checkbox during setup.*
* **Ollama (Local LLM Engine)**: Download via [ollama.com](https://ollama.com). 
  * After installation, open a background terminal terminal panel and pull the parameter layer weights natively:
    ```bash
    ollama run llama3.2
    ```
  * *Keep this terminal instance running in the background during execution.*
